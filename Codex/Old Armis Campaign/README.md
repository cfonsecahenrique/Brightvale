# New Armis Campaign

A **prequel** campaign set in the golden age of the **[[The Armisian Empire|Armisian Empire]]** — the bright, sea-faring, exploration-driven civilisation that will one day fall in the [[Apostasy]] and leave behind the ruins of the *Brightvale* setting.

**Tone:** Hellenic golden age × ancient Phoenician thalassocracy. Discovery, wonder, ambition — and the slow gathering of the storm to come.

➡️ **Players, start at [[Introduction]]** (`Introduction.md`) — a one-page front door to the setting.
➡️ **GMs, start at [[Overview]]** (`Worldbuilding/Overview.md`).

## Conventions
- **Hub note:** [[The Armisian Empire]] — link every faction, location, NPC, and lore note back to it.
- **Dating:** **AF (After Founding)**, counting up from the founding of Armis. The campaign present is **994 AF**. See [[Timeline (Armis)]].
- Follow the linking heuristics in the repo-root `CLAUDE.md` (cap ~3–4 links per note, specific → general).
- Index stubs are prefixed `_` so they sort to the top of each folder; replace/expand them as content grows.
